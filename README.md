# PlayWeb 🎮

**Play your favorite games in one place!**

PlayWeb is a gaming platform like Steam, but for web games.

You can find games, play with friends, and unlock achievements. All your games are in one place, so you can enjoy them without switching between different platforms.

## Features

- 🎮 Play different games
- 👤 Create your own account
- 🏆 Unlock achievements
- 🌐 Play games directly on the web
- 🎯 Enjoy multiplayer games

## About

PlayWeb is a project made to bring games together on one platform.

The project is still in development, and new features and games will be added over time.

**Have fun and enjoy playing! 🚀**
